# WeatherApp 🌤️

A weather application built with React that shows real-time weather data for any city in the world.

## Features
- Search weather by city name
- Toggle between °C and °F
- Dynamic background that changes based on weather conditions (sunny, cloudy, rainy)
- Shows temperature, weather description, humidity and wind speed
- Error handling for invalid city names

## Technologies
- React
- OpenWeather API
- CSS

## Getting Started

1. Clone the repository
2. Install dependencies

npm install

3. Create a `.env` file in the root of the project

VITE_API_KEY=your_api_key_here

4. Get your free API key at [openweathermap.org](https://openweathermap.org)
5. Run the app

npm run dev
